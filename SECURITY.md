# Security Policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please use the repository's **Security → Report a vulnerability** private
reporting flow. Do not publish API keys, private project files, unreleased
vulnerability details, or personal information in a public issue.

Include the affected version, macOS and Resolve versions, reproduction steps,
impact, and any suggested mitigation. Remove all credentials and private media
from logs and screenshots.

## Credentials

Never commit TokenHub keys, Apple signing certificates, notarization profiles,
passwords, or private keys. If a credential is exposed, revoke or rotate it at
the provider before removing it from Git history.
